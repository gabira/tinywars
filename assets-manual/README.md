# Zips manuais

Se o download automático falhar, coloque aqui os `.zip` baixados de https://pixelfrog-assets.itch.io/tiny-swords e rode `npm run assets`.

- `TS_old version_CC0 Licensed` (obrigatório — arquivo `Tiny Swords.zip`)
- `Tiny Swords (Free Pack).zip` (opcional)
- `Tiny Swords (Enemy Pack).zip` (opcional, **pago** — só se você comprou)

Os zips e os arquivos extraídos não são versionados (a licença proíbe redistribuir).
